# Pharmacy Label Monorepo

This is a pnpm monorepo containing a Next.js web app and a NestJS API.

## Prerequisites
- Node.js
- pnpm (corepack enable pnpm)

## Setup

1. Install dependencies:
   `ash
   pnpm install
   ``n
2. Environment Variables:
   Copy the .env.example files to .env in both pps/web and pps/api.

3. Run development server:
   `ash
   pnpm run dev
   ``n
This will start the Next.js app on http://localhost:3000 and the NestJS API on http://localhost:3001.
